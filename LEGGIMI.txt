QUEL POSTO — BISTROT ROMANO
Pacchetto completo della versione immersiva — 13 ottobre 2026

APERTURA SUL COMPUTER
1. Estrai tutto lo ZIP in una cartella.
2. Apri index.html con Chrome, Edge, Firefox o Safari aggiornati.
3. Scorri per aprire le porte, entrare nella sala e arrivare al piatto.
Mantieni la cartella assets accanto ai file HTML, CSS e JavaScript.

PUBBLICAZIONE SU GITHUB PAGES
Carica nella radice del repository index.html, style.css, app.js, motion.js,
la cartella assets e il file .nojekyll incluso. Nelle impostazioni Pages
scegli la pubblicazione dal branch e la cartella / (root).
Non serve installare pacchetti o eseguire una compilazione.

FILE
index.html: struttura, testi, contatti e modulo.
style.css: grafica responsive e animazioni.
app.js: interazioni, menu e prenotazione dimostrativa.
motion.js: progressione delle animazioni legate allo scroll.
assets/: tutte le immagini e i font usati dal sito.
FONT_LICENSE.txt: licenza dei font inclusi.
ASSET_PROMPTS.md: descrizione delle immagini generate.
